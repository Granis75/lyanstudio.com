WINDOWS CHECKOUT APPLICATION

AlCaisse

A practical checkout system that works offline.

AlCaisse brings sales, stock and cash sessions together in one Windows application, with transactions stored locally using SQLite.

Try the checkout simulation →

THE DESKTOP APPLICATION

Built for local retail operations.

A Windows desktop application developed for a client. The installed software is not distributed on this site; the interactive browser simulation lets you explore part of its checkout workflow.

01 / THE PRODUCT

Keep the checkout
moving.

At the counter, the essentials need to be fast and dependable. AlCaisse is designed around everyday shop routines: finding products, recording a sale, updating stock and closing the cash session.

Open session→Find product→Complete sale→Update stock→Close session
02 / WHAT IT DOES

Built around daily retail work.

Practical features without unnecessary complexity.

01

Checkout and receipts

Build a basket, complete sales and prepare receipts in a clear register workflow.

Sales · Receipts
02

Products and stock

Find items by name or barcode and keep stock movements connected to transactions.

Catalogue · Inventory

Cash sessions and recovery

Open and close cash sessions, review activity and use local backup and restore tools.

SQLite · Local data · Backups
03 / WINDOWS & WEB

Two different
experiences.

Windows application: the main AlCaisse software uses Electron and SQLite to operate locally. Printer, cash-drawer and fiscal compliance testing are not certified here, and the desktop installer is not publicly provided.

Browser simulation: a separate interactive checkout experience uses fictional information in your browser. It is for exploring the workflow, not for processing real sales or payments.
